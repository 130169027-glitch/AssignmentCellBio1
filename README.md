# Cell Biology Reflection Assignment

## The question

> What is one thing you learned in the cell biology course that sounds
> very interesting, or reflects the cell's phenomenal working style?

## How to submit

1. Fork this repository (or create a branch, if your instructor added you
   as a collaborator).
2. Add a new file inside the `submissions/` folder named:
   ```
   submissions/<your-roll-number>.md
   ```
3. Write your typed answer inside that file (150–300 words recommended).
   At the top of the file, include:
   ```
   Name: <your name>
   Roll number: <your roll number>
   ```
4. Open a Pull Request to this repository. Use your roll number as the
   PR title.
5. A bot will automatically check your submission for text similarity
   against other students' answers and post a comment with the result.
   This is a first-pass check for the instructor — it does not
   auto-reject anything.

## Rules

- **Write it yourself, in your own words.** Do not copy from AI tools
  (ChatGPT, Claude, Gemini, etc.), classmates, or the internet.
- Answers should reference something **specific from lecture or lab**
  — a specific mechanism, example, or moment that struck you. Vague,
  generic answers are easy to spot and will be sent back for a rewrite.
- Plagiarism/AI-generated answers found after review will require a
  resubmission and may affect your grade, per your instructor's policy.
- Late submissions: follow your instructor's stated deadline policy.

## What happens to your submission

- The automated check compares your answer's wording against every
  other submitted answer using text similarity (not an "AI detector" —
  it flags *matching phrasing between students*, which is a strong
  signal of copying).
- High-similarity pairs are flagged for the instructor to review by
  hand. A flag is not automatically a penalty — it's a starting point
  for a conversation.
